VLOOKUP 垂直查找 最高频

作用：按某列的值，从表格中查找并返回同行另一列的数据。

语法：=VLOOKUP(查找值, 表格区域, 返回列序号, 精确匹配0/近似1)

例：根据员工工号查姓名 → =VLOOKUP(A2, 员工表!$A$1:$C$100, 2, 0)
XLOOKUP 新一代查找 Office365/新WPS

作用：VLOOKUP 的升级版，可向左查、支持多条件、找不到可自定义提示。

语法：=XLOOKUP(查找值, 查找列, 返回列, 未找到提示)

例：=XLOOKUP(A2, B:B, A:A, "无此人") —— 向左查找也没问题
INDEX + MATCH 组合 万能查找

作用：比 VLOOKUP 更灵活的查找组合，任意方向、不影响原表结构。

语法：=INDEX(返回区域, MATCH(查找值, 查找列, 0))

例：=INDEX(C:C, MATCH(A2, B:B, 0)) —— 按 B 列值返回 C 列对应行
SUMIF / SUMIFS 条件求和 财务必备

作用：按一个或多个条件对区域求和。

语法：=SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2)

例：统计某部门 7 月销售额 → =SUMIFS(销售额列, 部门列, "销售部", 月份列, "7月")
IF 逻辑判断 入门必会

作用：条件成立返回一个值，否则返回另一个值。

语法：=IF(条件, 成立时, 不成立时)

例：业绩达标判断 → =IF(B2>=100000, "达标", "未达标")
COUNTIF / COUNTIFS 条件计数

作用：统计满足条件的单元格个数。

语法：=COUNTIF(区域, 条件)

例：统计迟到次数 → =COUNTIF(C:C, "迟到")
TEXT 文本格式化 日期/数字美化

作用：把数字、日期转成指定文本格式。

语法：=TEXT(值, "格式代码")

例：日期转"2025年8月1日" → =TEXT(A2, "yyyy年m月d日")；转星期 → =TEXT(A2,"aaaa")
SUBSTITUTE 替换指定文本

作用：把单元格里某个指定字符/词全部替换掉（比查找替换更灵活）。

语法：=SUBSTITUTE(原文本, 旧文本, 新文本)

例：去掉手机号空格 → =SUBSTITUTE(A2, " ", "")
ROUND / ROUNDUP / ROUNDDOWN 四舍五入

作用：控制小数位数，财务对账常用。

语法：=ROUND(数字, 小数位数)

例：保留2位 → =ROUND(A2*0.13, 2)
IFERROR 错误屏蔽 表格不显#N/A

作用：公式出错时显示指定内容，而不是难看的 #N/A。

语法：=IFERROR(原公式, 出错时显示)

例：=IFERROR(VLOOKUP(A2,B:C,2,0), "未找到")
